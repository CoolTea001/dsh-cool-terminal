# AGENTS.md

## Commit and push rules

1. Never commit or push on your own initiative — only run `git commit` / `git push` when the user explicitly asks for it. Report your changes and let the user decide when to commit or push.
2. Before committing, check for temporary files, large files, and sensitive content (keys, tokens, `.env`).
3. Write commit messages in English.

## Documentation language

1. `.md` files default to English.
2. Add a `.zh.md` as the Chinese companion.
3. `.md` and `.zh.md` must be updated together.
